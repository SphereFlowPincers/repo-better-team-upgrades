## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Shared Pool** | Upgrades contribute to a shared team pool instead of individual piles |
| **Contribution Log** | Track each player's upgrade contributions per session |
| **Upgrade Preview** | Preview upgrade effects before the team commits credits |
| **Fair Split** | Auto-suggest equitable upgrade distributions across the team |
